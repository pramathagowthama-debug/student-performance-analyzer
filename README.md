# STUDENT PERFORMANCE ANALYZER

A Python project to analyze student marks and calculate total, average, percentage, grade, and pass/fail result.

## Project Overview

This project takes a student's marks in different subjects and automatically calculates their academic performance.

## Features

- Accepts student name and subject marks
- Calculates total marks
- Calculates average marks
- Calculates percentage
- Assigns a grade
- Determines pass/fail status
- Displays a student performance report

## Technologies Used

- Python
- Google Colab
